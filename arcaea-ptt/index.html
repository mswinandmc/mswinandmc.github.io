Arcaea 移动版 v7.0+ 潜力值机制

单曲 ptt 计算器

输入本次结算分数与谱面定数，勾选「本次通关」，实时得到单曲潜力值。 通关（TC / Easy Clear / FR / PM）额外 +0.200，Track Lost 不加。

输入

分

0 – 10,000,000

定数

一位小数；当前版本最高定数为 12.0

本次成绩的通关状态

奖励只绑本次通关状态，与该谱历史是否 TC 无关。

最终单曲 ptt
12.450

若本次 Track Lost：12.250（少 0.200）

通关（+0.200） Track Lost 竖线：当前分数

公式依据 Arcaea 移动版 v7.0（v7.3.0 仍适用）：score ≥ 1e7 → 定数+2；9.8e6 ≤ score < 1e7 → 定数+1+(score−9.8e6)/200000；score < 9.8e6 → 定数+(score−9.5e6)/300000，再 +0.2（通关），下限 0。

结果保留三位小数展示（四舍五入）；下限与通关奖励都按未取整的原始值计算。全部计算在你的浏览器本地完成，不上传任何数据。
